
**Scope:** Recognise, confirm, and exploit injection vulnerabilities.

| Injection Type                                    | Route to                              |
| ------------------------------------------------- | ------------------------------------- |
| User input executed as OS command                 | Command Injection                     |
| Serialised object accepted as input               | Insecure Deserialisation              |
| User input passed into an AI/LLM prompt           | Prompt (A.I.) Injection               |
| User input rendered inside a server-side template | Server Side Template Injection (SSTI) |
| User input passed into a database query           | SQL Injection                         |
